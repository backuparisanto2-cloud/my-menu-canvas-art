# Kantin Inyong Menu

Nama apps menu kantin Inyong, web responsive tapi untuk mobile diusahakan gambar hampir full screen. 

Buat halaman web static menu restorant mobile first scrollable ke bawah, bisa di export ke html beserta gambar nya, animasi fade in smooth tapi ringan, per gambar per halaman tanpa Header, hanya sidebar menu, bisa tag halaman untuk mengingat favorit hilang per sesi refresh, daftar halaman dari indexing gambar, utamakan 70% kecepatan web, compress gambar maksimal size 50KB webp tapi tetap jelas, ketika sudah paling bawah bisa top ke atas, scroll fade efek elegant smooth sangat ringan mobile first utamakan kecepatan web
